# Eye Control Yes No

**Eye Control Yes No** is a simple and accessible communication aid that helps users express choices using large visual cards.

The app can be used to answer **Yes**, **No**, or **Maybe** through different interaction methods depending on the user’s needs and abilities.

Users can select cards using:

* eye gaze;
* touch;
* swipe gestures.

Once a card is selected, the answer is spoken aloud in the selected language.

## Main Features

* Large visual communication cards
* Yes / No cards
* Optional Maybe card
* Eye gaze selection on compatible devices
* Touch selection
* Swipe selection
* Adjustable dwell time
* Voice output
* Female and male voice options
* Multiple languages
* Light mode and dark mode
* Simple and accessible interface
* No account required
* No advertising
* No internet connection required for the main features

## Custom Themes

Eye Control Yes No allows users to create personalised communication themes.

A theme can contain **2 or 3 cards**, depending on the user’s needs.

Each card can be customised with:

* text;
* colour;
* an emoji;
* a photo selected from the iPhone;
* a photo taken directly with the camera.

Themes can be created for many everyday situations, such as:

* emotions;
* meals;
* drinks;
* health;
* comfort;
* activities;
* people;
* places;
* routines;
* urgent needs.

## Import and Export Themes

Custom themes can be exported and imported using the `.egthemes.zip` format.

This makes it possible to share themes with other people, such as:

* family members;
* carers;
* healthcare professionals;
* educators;
* support workers.

Imported themes can include text, colours, emojis and photos.

## Accessibility

The app is designed to be simple, clear and accessible.

It provides several selection methods so that the user can choose the one that best suits their abilities:

* gaze selection;
* direct touch;
* swipe gestures.

On compatible iPhone and iPad models with Face ID and a TrueDepth camera, the app can use eye gaze tracking to validate a card after a configurable dwell time.

## Privacy

### TrueDepth API and Face Data

Eye Control Yes No uses Apple’s ARKit Face Tracking and TrueDepth camera features to estimate the user’s gaze direction and allow the user to select communication cards.

The app may process the following face-related information on the device during use:

* face position and orientation;
* eye direction and gaze-related information provided by ARKit;
* temporary tracking data needed to determine whether the user is looking at a card.

This information is used only to enable eye gaze selection inside the app.

Eye Control Yes No does not store, save, record, transmit, sell or share face data.

Face tracking data is processed locally on the device in real time and is discarded immediately after use.

Face data is not used for identification, authentication, advertising, analytics, profiling or tracking.

No face data is shared with third parties.

### Photos

Photos can be used only when the user chooses to customise a card with an image.

Photos selected or taken by the user are used to personalise cards and themes.

Theme export is initiated manually by the user.
